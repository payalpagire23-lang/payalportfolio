# Payal Pagire - Portfolio Website

A responsive personal portfolio website built with **HTML** and **CSS** only (no frameworks, no JavaScript).

## Preview

A fixed sidebar with photo, name, navigation and resume download button, with a scrolling main area containing the following sections:

- Hero / Welcome
- About Me
- Education (timeline)
- Projects
- Experience
- Certification
- Skills
- Resume
- Contact

## Project Structure

```
portfolio/
├── index.html                      # Main page
├── style.css                       # All styling
├── README.md                       # This file
├── images/
│   └── photo.jpeg                  # Profile photo
└── resume/
    └── Payal_Pagire_Resume.pdf     # Resume (view / download)
```

## How to Run

1. Unzip the folder.
2. Open `index.html` in any browser (double-click it).

**Using VS Code:** install the *Live Server* extension, right-click `index.html` and choose **Open with Live Server**.

## How to Customize

| What to change | Where |
| --- | --- |
| Text, projects, skills, contact details | `index.html` |
| Colours | `:root` variables at the top of `style.css` (`--plum`, `--accent`, `--bg`) |
| Profile photo | Replace `images/photo.jpeg` (keep the same name, or update the path in `index.html`) |
| Resume | Replace `resume/Payal_Pagire_Resume.pdf` (keep the same name) |

## Features

- Fixed sidebar navigation with smooth scrolling
- Resume view and download buttons
- Hover effects on cards, tags and buttons
- Fully responsive: the sidebar turns into a menu button on mobile
- Lightweight and fast, with no external libraries
